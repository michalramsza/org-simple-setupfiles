# Simple setup files for Org-mode

## How to use

This repository contains simple setup files for Org-mode and HTML conversion. To use a setup file, include the following line in the header of your Org file:

```
#+SETUPFILE: https://raw.githubusercontent.com/michalramsza/org-simple-setupfiles/main/style-01/org-style-01.setup
```

This will apply the first setup file. To use a different setup file, simply update the path accordingly.
